A clearer path from “I should study” to “I know this.”

The product is built around a practical sequence: choose the right material, learn with context, then test under tighter constraints.

01

Find or build the right subject.

Start from curated material or create a subject for your own language track, exam, profession, or specialized vocabulary goal.

02

Learn with media and repetition.

Study inside organized folders and collections while spaced review keeps important material circulating at the right frequency.

03

Test for retention, not just exposure.

Switch into test mode when you need to measure recall, expose weak spots, and convert short-term recognition into durable knowledge.

Two test directions for stronger recall.

Aliolo test mode is not a single static quiz. It supports both standard and reverse practice so learners can check memory from both sides of the same concept.

N

Normal mode

Question to answer

Use the standard direction when you want to recognize the prompt, then actively recall the correct answer. This is the default path for building confidence and reinforcing primary recall.

R

Reverse mode

Answer to question

Flip the direction when you want stricter retrieval. Reverse mode exposes weak understanding faster because learners must work backward from the answer, image, or media cue to the source concept.
